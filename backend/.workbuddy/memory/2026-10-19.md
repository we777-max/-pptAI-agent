### 走查发现（待办候选）
1. **死代码**：`app/routes.py`、`app/provider.py`、`app/service.py` 与 `app/api/routes.py`、`app/agent/provider.py`、`app/agent/service.py` 内容逐字节相同，且无任何引用（main.py 只挂 api.routes）。易误改，建议删除。
2. **Renderer 缺失**：README 描述的 `renderer/`（TS + PptxGenJS）、`docker-compose.yml`、`sample/deck.json` 在仓库中不存在，`docker compose up` 无法工作。
3. **Mock provider 会压平 deck**：`agent/provider.py` 返回 `slides=[slide]`（只保留第 1 页）并整体替换原元素，多页 deck 会被截断。
4. `SlideIR.elements_within_canvas` 只校验元素数量（≤500），边界校验注释交给渲染器，但 stub 渲染器不校验，越界元素不报错。
5. `AUTO_CREATE_TABLES=true` 与 Alembic 并行使用，schema 有漂移风险。
6. 仓库未 git 初始化；`ppt_agent.db`、`data/*.stub.pptx` 缺少 .gitignore。
7. 异步任务用 FastAPI `BackgroundTasks`：进程重启即丢失，多副本下失效（README 自己建议换 Celery/Redis 或 durable execution）。
